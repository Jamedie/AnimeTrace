# Conventions du projet AnimeTrace

Lire et appliquer `H:\Mon Drive\LLM\AGENTS.md`, puis les fichiers de suivi du projet, avant de travailler. Sur une autre machine, retrouver le dossier LLM synchronisé.

## Documentation

- Conserver les documents de référence dans `docs/`.
- Nommer les documents en français, en MAJUSCULES, sans accents ni espaces ; séparer les mots par des tirets et utiliser l’extension `.md`.
- Exemples : `FONCTIONNALITES.md`, `MODELE-DONNEES.md`.
- Utiliser des noms stables décrivant le sujet, sans numéro de version ni date pour les références vivantes. Réserver les versions et dates aux archives et rapports ponctuels.
- Garder les accents et l’orthographe française dans le contenu.
- Utiliser des liens relatifs entre documents et les mettre à jour lors d’un renommage.
- Distinguer les fonctionnalités existantes, prévues, à préciser et différées.
- Employer les termes métier de façon constante : anime → saison → épisode → version de lecture. Une source de lecture est un accès au contenu, distinct de cette hiérarchie. MyAnimeList s’abrège en MAL après sa première mention.
- Ne pas écraser les documents historiques 0.3.6 du suivi partagé avec les références de la refonte ; recopier ces dernières dans son sous-dossier `docs/`.

Ces règles concernent la documentation. Les conventions du code seront définies avec l’architecture de la refonte.
